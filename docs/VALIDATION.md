# 验证记录

本次初始化将既有原型整理进 GeminiDepthPort，并保留 Web 管理容器、两台相机容器、统一启动流程和 systemd 模板。

## 初始化验证（原始基线）

- 48 项离线单元测试：配置、型号接口、Web 绑定与保存、请求保护、操作锁、模拟健康检查、图像缓冲区处理及统一启动门槛。
- Python 编译检查。
- JavaScript 语法检查。
- deploy.sh 与容器入口 Shell 语法检查。
- 包含 cameras profile 的 Docker Compose 配置检查。
- Git 补丁空白检查。

初始化前的 Web 原型还验证过浏览器页面、角色切换、保存到文件、未连接设备时拒绝预览，以及回环 HTTP 接口。本次未再次验证新项目品牌对应的浏览器页面；docs/images/web-console.png 是初始化前的参考截图。

## 尚未验证

- 目标 Linux 主机上的管理/采集镜像构建。
- Gemini 335L 与 Gemini 2 的 USB、固件和真实采集。
- ROS 图像预览与实际 JPEG 编码。
- 双机持续出帧、带宽、延迟、相互干扰、拔插恢复。
- udev 安装和 systemd 开机编排。
- 机器人关节时间、CameraInfo、外参/手眼标定。

初始化 CI 仅运行离线测试和静态检查，不会因 CI 通过而表示上述真机能力已经通过验收。发布前按 docs/DEPLOYMENT.md 在目标主机记录实测结果。


## Compose 与自启改进验证

- 57 项离线单元测试通过，新增部署目录 UID/GID、socket 组、管理容器与采集容器区分、逐台出帧顺序、自定义公开端口与外部开机任务状态刷新回归测试。
- ShellCheck、Bash/Python/JavaScript 语法、Compose 两种 profile、含空格路径和自定义端口展开检查通过。
- Web 管理运行环境镜像在 linux/arm64 Docker 构建环境实际构建成功，验证 Python 3.12.15、PyYAML 6.0.2、Compose v2.33.0 可用。
- 在非 root、所有 capabilities 移除、根文件系统只读、无网络、无 Docker socket/设备访问的测试容器中，真实 HTTP 健康检查、项目页面、状态接口、配置原子保存以及操作/CSRF/Host 拒绝测试通过。
- 当前 Docker 构建环境不共享本机目录，因此上述容器 HTTP 验证把源码放入临时可写目录；没有据此宣称实际宿主机 bind mount、socket GID 或 systemd 已经过本地验证。新增 Linux CI 作业使用 checkout 所有者 UID/GID 与同绝对路径挂载，再执行相同 HTTP 测试。

Web 管理镜像的构建验证不等于采集 SDK 镜像、真实双机采集或 systemd 开机验证。剩余真机项目仍按上面的验收列表以及 COMPOSE.md 执行。


## 性能评估与测试协议（文档阶段）

新增 [性能评估](PERFORMANCE.md)、[基准测试方案](BENCHMARKS.md)、空白结果模板和静态计算模型，基于 `2526cc5` 设计对照。只完成源码路径核对、模型算术和文档一致性检查；未新增性能采集器，未执行 13900K 真机 CPU、P99、内存、能量或 SDK 重构对照，也未开始 Rust。

原有单元测试/容器冒烟测试通过不替代真机性能验证。后续结果按 `docs/benchmarks/RESULT_TEMPLATE.md` 单独记录；公开汇总不得包含真实序列号和现场私有数据。性能方案已与 `92c2fb3` 的公开接口/阶段二计划区分：WP0 双机 RGB8 原型有静态模型，WP1 三机原生 YUYV 待实现、待受控测试，不混用结果。

### 修改包 C：首次 CI 构建结果与修复

公开官方 ROS 驱动本体在 Linux amd64 CI 中完成编译，独立 C++ 缓冲区内存检查通过。完整镜像随后在 SDK 合成测试编译阶段失败：单独包含 `Frame.hpp` 时，SDK 的 Sensor/Device 类型只有前置声明。测试已改为包含官方 `ObSensor.hpp` 总入口头文件；不创建 Context 或 Pipeline，不增加设备访问。

该修复需要 CI 重新验证。SDK 合成测试、ROS 往返与完整镜像通过之前，仍不将修改包 C 标记为完成构建验收。


## 默认三机与消费接口改进（离线验证）

默认 schema v2 三机 RGB-D 草稿、动态 Web 编辑/预览/确认、可靠 QoS 配置与实际端点检查、只读 ROS 标定快照、通信/深度/时间语义探针已加入。所有新增测试使用合成设备与消息，没有导入消费方配置、设备身份、标定或采集样本。

- 180 项离线测试执行：179 通过，1 项 Linux flock 专属测试在本机跳过。
- Python 编译、JavaScript/Shell 语法、根 Compose 与合成三机生成 Compose schema 检查通过。
- 浏览器验证默认三槽显示及第三台相机切换，无脚本错误；没有绑定或打开物理设备。
- 临时副本中的真实 HTTP 冒烟通过：健康、页面、三机状态、原子配置保存及操作/CSRF/Host 拒绝检查。
- 独立审查发现的 v2 预览确认摘要不一致、标定 stdin 协议和畸变模型结构检查均已修复并覆盖测试。

本轮未重新构建完整采集镜像，未连接物理三机，也未完成真实深度尺度、时间映射、跨发行版通信、标定精度或持续录制验收。上述结果不替代目标 Linux 环境与消费方端到端测试。
